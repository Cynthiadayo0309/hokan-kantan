施設内訪問看護 月額費用シミュレーター

施設内で医療保険の訪問看護を利用する1人の利用者について、1か月分の訪問予定と算定条件を入力し、 月額費用と利用者負担額の概算を確認するためのWindows向けデスクトップアプリです。

月間予定を一覧で確認
日別の訪問内容を選択式で入力
費用明細と概算合計を表示

本計算結果は概算です。実際の算定・請求内容を保証するものではありません。

Purpose

施設内訪問看護の月額費用を、確認しやすく

こんな場面を想定しています

  • サービス提供票を見ながら、1人分の月間訪問予定を整理したい。
  • 訪問時間帯や加算条件を入力し、概算の費用感を確認したい。
  • 自己負担割合を設定して、利用者負担額の目安を把握したい。

対象外のこと

請求処理、レセプト作成、正式な請求額の確定、複数利用者の一括計算は行いません。 あくまで現場確認用の概算ツールとして使用します。

1 月間予定を入力
2 日別訪問を登録
3 費用明細を確認

Screen 1

月間入力画面

利用者名、施設名、対象年月、同一建物人数区分、自己負担割合を入力し、対象月の日付を一覧で確認します。 訪問内容が登録済みの日付には要約が表示されます。

  • 日付を1回クリックして日別入力を開きます。
  • 土日・祝日や今日が視覚的に分かります。
  • 入力済みの日付は職種、時刻、時間帯を要約表示します。

Screen 2

日別入力ダイアログ

その日の訪問内容を、上から順に選択して登録します。開始時刻・終了時刻から訪問時間と時間帯を自動表示します。

  • 基本療養費と管理療養費を別々に選択できます。
  • 1日複数回の訪問に対応します。
  • 時間帯またぎは警告表示で確認できます。
  • 加算条件は必要な場合だけ開いて選択します。

Screen 3

費用明細画面

入力済みの月間予定から、基本療養費、管理療養費、各種加算、月額費用総額、利用者負担額の概算を表示します。

  • 同じ算定条件は、可能な範囲でまとめて表示します。
  • 警告がある明細は内容確認が必要な行として表示します。
  • 自己負担割合が未設定の場合、利用者負担額は表示しません。

Features

主な機能

時間帯の自動判定

深夜、早朝、通常、夜間を時刻から判定し、時間帯またぎの場合は内訳を表示します。

複数回訪問

1日2回以上の訪問を登録でき、同じ日の訪問時間が重複する場合は保存できません。

加算項目の選択

複数名訪問、長時間訪問、緊急訪問、特別管理加算、退院関連の項目を選択できます。

自己負担額の概算

1割、2割、3割の自己負担割合を設定し、月額費用総額に対する概算額を表示します。

料金マスターについて

金額や算定条件は料金マスターを参照します。料金マスターの内容により計算結果が変わります。 正式な費用計算には、制度・通知・専門職の確認に基づく料金マスター更新が必要です。

Install

導入と使用時の注意

導入の流れ

  1. インストーラーを実行します。
  2. 画面の案内に従ってインストールします。
  3. デスクトップアイコンまたはスタートメニューから起動します。
  4. 月間予定を入力し、費用明細を確認します。

利用環境

  • Windows 64bit PC向けです。
  • インターネット接続なしで使用できます。
  • ログインやユーザー登録は不要です。
  • 入力データは利用者ごとのPC内に保存されます。

重要な注意事項

  • 本アプリは概算ツールです。正式な請求、レセプト、請求額確定には使用しないでください。
  • 未署名インストーラーでは、Windowsの警告が表示される可能性があります。
  • アンインストールしても、入力データが自動削除されない場合があります。
