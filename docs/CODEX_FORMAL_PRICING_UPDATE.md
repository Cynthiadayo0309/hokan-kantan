# Codex追加指示書：正式料金マスター対応

> 対象アプリ：訪看かんたん計算  
> 本書はリポジトリ直下の `AGENTS.md` を補足する。正式料金・算定条件について競合する場合は本書を優先すること。

## 1. 目的

現在のサンプル料金を、令和8年度の医療保険における訪問看護療養費へ置き換える。

対象：

- 訪問看護基本療養費
- 訪問看護管理療養費
- 夜間・早朝、深夜訪問看護加算
- 難病等複数回訪問加算
- 複数名訪問看護加算
- 長時間訪問看護加算
- 緊急訪問看護加算
- 特別管理加算
- 退院時共同指導加算
- 退院支援指導加算
- 職種、同一建物人数、週内・月内訪問日数による単価判定
- 利用者負担額の端数処理

前提：

- 医療保険
- 訪問看護ステーション
- 精神科訪問看護、包括型訪問看護療養費は対象外
- 適用開始日：2026-06-01
- 金額は円単位
- 本アプリは正式請求ではなく概算計算

画面には引き続き次を表示する。

> 本計算結果は概算です。実際の算定・請求内容を保証するものではありません。

## 2. 実装原則

### 2.1 単価と算定可否を分離する

- `pricing_rules`：単価、区分、適用期間、算定単位
- `eligibility_rules`：職種制限、対象者要件、回数上限、週・月・日単位の制限

料金だけを見て算定してはならない。

### 2.2 金額をハードコーディングしない

Vueコンポーネント、Pinia、IPC、計算サービスへ単価を直接記述しない。SQLiteの料金マスターから取得する。

### 2.3 訪問回数と算定回数を分離する

1日に複数回訪問しても、訪問看護基本療養費を訪問回数分掛けない。

別管理する項目：

- 実際の訪問回数
- 基本療養費の算定回数
- 複数回訪問加算の算定回数
- 時間帯加算の算定回数
- 複数名訪問加算の算定回数

## 6. 日数カウント

### 週内訪問日数

- 日曜日～土曜日
- 同日複数回でも1日
- 週3日目まで／4日目以降を判定

### 月内訪問日数

- 対象利用者の当月訪問日数
- カレンダー上の日付ではない
- 同日複数回でも1日
- 15、16、20、21、24、25日目等を判定

### 緊急訪問加算日数

通常訪問日数とは別にカウントする。

## 7. 端数処理

医療費総額は整数円の合計とし、丸めない。

利用者負担額は自己負担割合を掛けた後、10円未満四捨五入する。

```ts
export function roundCopaymentToTenYen(amount: number): number {
  return Math.round(amount / 10) * 10;
}
```

テスト例：

| 入力 | 結果 |
|---:|---:|
| 1,234円 | 1,230円 |
| 1,235円 | 1,240円 |
| 1,239円 | 1,240円 |

公費、高額療養費、自己負担上限は対象外のため「利用者負担額の概算」と表示する。
