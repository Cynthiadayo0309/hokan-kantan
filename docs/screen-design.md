# 画面設計

## 月間入力画面

参考画像1のような横長のサービス提供票を参考にする。対象月の日付を1日から末日まで横に並べ、左端の項目列と日付行を固定する。

セルには要約だけを表示する。詳細入力は日付セルクリックで開く日別入力ダイアログに集約する。

## 日別入力ダイアログ

上から順に入力すれば保存できる構成にする。利用者名と施設名以外はプルダウン中心にする。

訪問回数に応じて開始時刻、終了時刻、終了日区分の行を動的に増減する。訪問時間、時間帯、内訳は自動表示とする。

保存、削除、閉じるの3ボタンのみ配置し、削除は確認する。

## 費用明細画面

参考画像2のように明細テーブルを主役にし、下部または右下に合計欄を配置する。

表示列は区分、サービス内容、算定条件、対象日、算定回数、単価、金額、備考とする。

自己負担割合が未設定の場合、利用者負担額は表示しない。
