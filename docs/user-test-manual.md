# 訪看かんたん計算 簡易説明書

この説明書は、使用者テスト用の簡単な手順書です。

「訪看かんたん計算」は、施設内で訪問看護を利用する1人の利用者について、1か月分の訪問予定を入力し、月額費用の概算を確認するためのアプリです。

本計算結果は概算です。実際の算定・請求内容を保証するものではありません。

## 1. インストールする

1. `訪看かんたん計算_Setup_0.1.0.exe` をダブルクリックします。
2. 画面の案内に従ってインストールします。
3. インストールが終わったら、デスクトップのアイコンまたはスタートメニューから起動します。

未署名のため、Windowsの警告が表示される場合があります。その場合は、配布元に確認してから実行してください。

## 2. 月間予定を入力する

起動すると「月間予定を入力」画面が表示されます。

上から順に入力してください。

1. 利用者名を入力します。
2. 施設名を入力します。
3. 対象年月を選びます。
4. 同一建物人数区分を選びます。
5. 自己負担割合を選びます。
6. 必要に応じて、ステーション区分、管理療養費用人数区分、特別管理加算などを選びます。

基本療養費は、現在「訪問看護基本療養費（Ⅱ）」のみ対応しています。

`1人` 区分を選んだ場合、訪問看護基本療養費（Ⅰ）が必要になることがあります。訪問看護基本療養費（Ⅰ）は現在未対応のため、警告が表示され、その項目が合計に含まれない場合があります。

## 3. 日別の訪問内容を入力する

月間予定表の日付を1回クリックすると、その日の入力画面が開きます。

1. 訪問看護基本療養費が対象かどうかを選びます。
2. 訪問看護管理療養費が対象かどうかを選びます。
3. 訪問職種を選びます。
4. 1日当たりの訪問回数を選びます。
5. 各回の開始時刻と終了時刻を選びます。
6. 必要に応じて、夜間等訪問の求め、複数回訪問、複数名訪問、長時間訪問、緊急訪問、退院関連の項目を選びます。
7. 「この日の内容を保存」を押します。

訪問時間と訪問時間帯は自動で表示されます。

複数回訪問の場合は、回数分の時刻入力欄が表示されます。同じ日の訪問時間が重なっている場合は保存できません。

## 4. 月額費用を計算する

1か月分の入力が終わったら、月間入力画面の下にある「月額費用を計算」を押します。

入力内容に問題がなければ、「費用を確認」画面へ移動します。

## 5. 費用明細を確認する

「費用を確認」画面では、次の内容を確認できます。

- 訪問看護基本療養費合計
- 訪問看護管理療養費合計
- 各種加算合計
- 月額費用総額
- 利用者負担額の概算

自己負担割合を「未設定」にした場合、利用者負担額の概算は表示されません。

明細に警告が表示されている行は、内容を確認してください。正式料金が見つからない項目や、算定条件が不足している項目は、合計に含まれない場合があります。

月間入力へ戻る場合は「月間入力へ戻る」を押します。戻っても入力内容は消えません。

## 6. 入力内容を削除する

### 1日分だけ削除する

1. 月間予定表で、削除したい日付をクリックします。
2. 「この日の内容を削除」を押します。
3. 確認画面で問題なければ削除します。

### すべて削除する

月間入力画面の「入力内容をすべてクリア」を押します。

実行前に確認画面が表示されます。削除すると、入力済みの訪問内容は元に戻せません。

## 7. よくある警告

### 時間帯またぎ

訪問時間が通常、夜間、深夜など複数の時間帯にまたがっています。入力時刻が正しいか確認してください。

### 正式料金が見つからない

入力した条件に合う料金が登録されていない場合に表示されます。その項目は合計に含まれないことがあります。

### 1人区分の警告

現在は訪問看護基本療養費（Ⅱ）のみ対応しています。訪問看護基本療養費（Ⅰ）が必要な条件は合計に含まれない場合があります。

### 算定条件が不足している

夜間等訪問、複数名訪問、緊急訪問などで、必要な確認項目が不足している場合に表示されます。入力内容を確認してください。

## 8. テスト時に確認してほしいこと

実際に使ってみて、次の点を確認してください。

- インストールできるか
- 起動できるか
- 利用者名、施設名、対象年月を入力できるか
- 日付をクリックして日別入力画面を開けるか
- 訪問時刻を選べるか
- 訪問内容を保存できるか
- 月額費用を計算できるか
- 費用明細が見やすいか
- 警告の意味が分かるか
- 入力内容を削除できるか
- 操作中に迷うところがないか

## 9. 問題があった場合

問題があった場合は、できる範囲で次の内容を控えてください。

- どの画面で起きたか
- どのボタンを押した後に起きたか
- 入力していた日付や時刻
- 表示されたメッセージ
- もう一度同じ操作をすると同じ問題が起きるか

画面の写真を残せる場合は、写真もあると確認しやすくなります。

## 10. 終了する

アプリを終了する場合は、画面右上の閉じるボタンを押します。

入力内容は保存されます。次回起動したときに、前回の内容を確認できます。
