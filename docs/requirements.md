# 訪看かんたん計算 要件整理

## 目的

施設内で医療保険または介護保険の訪問看護を利用する1人の利用者について、1か月分の訪問予定と算定条件を入力し、月額費用総額と自己負担額の概算を表示する。

本アプリは概算ツールであり、請求処理、レセプト作成、正式な請求額の確定は行わない。

## MVP範囲

- Windows 64bit向けデスクトップアプリとして配布する。
- Electron、Vue 3、Vuetify、TypeScript、SQLiteを使用する。
- 起動時に医療保険・介護保険を選択し、各保険は「月間入力画面」「費用明細画面」の2段階で操作する。
- 保険を選び直しても、医療・介護それぞれの入力内容を保持する。
- 日別訪問内容は月間入力画面の日付セルからダイアログで登録する。
- 訪問時間、時間帯、時間帯別内訳は自動計算する。
- 料金はSQLiteの料金マスターから取得する。
- 訪問看護基本療養費（Ⅱ）を正式料金として扱い、訪問看護基本療養費（Ⅰ）は未実装として警告し合計に含めない。
- サンプル料金は削除せず無効化し、正式料金だけで計算できる場合はサンプル料金警告を表示しない。
- 高額療養費自己負担限度額は70歳以上・外来個人ごとの概算のみ対応し、世帯合算、多数回該当、年間上限、公費、他医療機関分は対象外とする。
- 費用明細画面から、確認用の印刷プレビュー、印刷、PDF保存、Excel保存を行える。
- 利用者が使用権限のある画像を選び、アプリ用のカスタムアイコンとして保存できる。

## 介護保険対応範囲

- 指定訪問看護ステーションによる訪問看護・介護予防訪問看護を対象とする。
- 看護職は開始・終了時刻とは別に、20分未満、30分未満、30分以上1時間未満、1時間以上1時間30分未満の算定区分を選択する。
- 新規入力では訪問時間から公式区分を仮選択し、利用者が変更した区分を料金計算で優先する。実時間と選択区分が一致しない場合は警告するが保存できる。
- PT・OT・STは20分を1回として算定し、端数時間を警告する。1日3回以上は90%算定とする。
- 要介護・要支援、准看護師90%、夜間・早朝・深夜、長時間、同一建物、主要月額加算、リハビリ減算を計算する。
- 2026年6月以降は、選択時のみ介護職員等処遇改善加算1.8%を適用する。
- 地域区分1～7級地・その他の地域単価で総費用を計算する。
- 区分支給限度基準額、他サービス利用額、高額介護サービス費、公費、生活保護、医療介護合算は計算しない。
- 医療保険優先条件は自動判定せず警告する。今回列挙していない加減算は合計へ含めない。

## 対象外

ログイン、マスター管理、請求、レセプト、CSV、自動アップデート、クラウド同期、複数PC共有、複数利用者の一括計算は実装しない。

印刷、PDF、Excelは概算結果の確認用とし、請求書、レセプト、正式な請求データとしては扱わない。

## 常時表示する注意

- 本計算結果は概算です。実際の算定・請求内容を保証するものではありません。
- サンプル料金を使用している場合のみ、次を表示する。

```text
現在はサンプル料金を使用しています。正式な費用計算には料金マスターの更新が必要です。
```
