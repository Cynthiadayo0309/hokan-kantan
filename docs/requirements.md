# 訪看かんたん計算 要件整理

## 目的

施設内で医療保険の訪問看護を利用する1人の利用者について、1か月分の訪問予定と算定条件を入力し、月額費用総額と自己負担額の概算を表示する。

本アプリは概算ツールであり、請求処理、レセプト作成、正式な請求額の確定は行わない。

## MVP範囲

- Windows 64bit向けデスクトップアプリとして配布する。
- Electron、Vue 3、Vuetify、TypeScript、SQLiteを使用する。
- 画面は「月間入力画面」と「費用明細画面」の2画面のみとする。
- 日別訪問内容は月間入力画面の日付セルからダイアログで登録する。
- 訪問時間、時間帯、時間帯別内訳は自動計算する。
- 料金はSQLiteの料金マスターから取得する。
- 訪問看護基本療養費（Ⅱ）を正式料金として扱い、訪問看護基本療養費（Ⅰ）は未実装として警告し合計に含めない。
- サンプル料金は削除せず無効化し、正式料金だけで計算できる場合はサンプル料金警告を表示しない。

## 対象外

ログイン、マスター管理、請求、レセプト、PDF、CSV、印刷、自動アップデート、クラウド同期、複数PC共有、複数利用者の一括計算は実装しない。

## 常時表示する注意

- 本計算結果は概算です。実際の算定・請求内容を保証するものではありません。
- サンプル料金を使用している場合のみ、次を表示する。

```text
現在はサンプル料金を使用しています。正式な費用計算には料金マスターの更新が必要です。
```
